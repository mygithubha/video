# 映界 Video Library

基于 Next.js 的影视发现站点。影视资料来自 TMDB；TMDB 不提供完整影片文件。

## 环境变量

```env
MOVIE_DB_URL=https://api.themoviedb.org/3
MOVIE_DB_API_KEY=你的TMDB_API_KEY
```

请在 Vercel 项目环境变量中设置密钥，不要提交到 GitHub，也不要使用 NEXT_PUBLIC_ 前缀。

## 版权与播放

本站不提供盗版解析。只有在逐项核验版权、许可及再分发/嵌入条件后，才可加入播放源。网站不主动注入广告，但第三方托管平台可能自行展示广告。

## 本地运行

```bash
npm install
npm run dev
```
